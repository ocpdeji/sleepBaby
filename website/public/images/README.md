# Images

Drop your images here. The site degrades gracefully if any are missing.

## Required / recommended

```
public/images/
├── og-default.jpg          # 1200×630 — default social share image
├── kate.jpg                # author photo (About + blog author bio)
├── logo.png                # used in blog JSON-LD publisher schema
├── products/
│   ├── book.jpg            # Sleep, Baby. Please.
│   ├── bundle.jpg          # Premium Bundle
│   ├── toddler.jpg         # Toddler Bedtime Kit
│   └── newborn.jpg         # Newborn Starter Kit
└── blog/                   # optional local blog covers
```

You can reuse covers from the parent project, e.g.:
- `payhip_01_bundle_stack.png`  → `products/bundle.jpg`
- `1. Sleep_Baby_Please_SixAndThriving_2026 (1)_page-0001.jpg` → `products/book.jpg`

The included blog posts reference Unsplash URLs, so they work out of the box.
